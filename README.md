# Module 5: Stacks and Queues

## Description
This project demonstrates stacks and queues using arrays and linked lists.

## Files
- `README.md` - Program documentation
- `analysis.md` - Answer to the analysis question
- `applications.py` - Balanced parentheses checker and print queue simulation
- `array_queue.py` - Circular array queue
- `array_stack.py` - Array-based stack
- `linked_queue.py` - Linked-list queue
- `linked_stack.py` - Linked-list stack and Node class
- `main.py` - Menu-driven program
- `sample_runs.txt` - Example operations and outputs

## How to Run
1. Install Python 3.
2. Keep all project files in the same folder.
3. Open a terminal in the project folder.
4. Run `python main.py`.

To run the application examples, run `python applications.py`.

- ArrayStack
- LinkedStack
