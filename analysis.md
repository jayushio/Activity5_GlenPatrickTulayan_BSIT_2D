# Analysis Question

A linked-list stack pushes at the head because adding a node at the head takes O(1) time. Removing the top node from the head also takes O(1) time. If we use the tail, we need to find the node before the last node, which takes O(n) time in a singly linked list. The array queue must be circular so that empty spaces at the beginning can be reused without shifting all the elements.
